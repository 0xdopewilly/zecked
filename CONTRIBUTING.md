# Contributing to ZECKED

Thanks for wanting to help. ZECKED is small and moves fast, so keep changes focused.

- **Bugs and ideas:** open an issue with steps to reproduce (device, browser, what you expected).
- **Pull requests:** one change per PR, with a short description of what and why. Run `npx tsc --noEmit -p .` and `npx next build` before opening it.
- **Security issues** (custody, the vault, sign-in): please don't open a public issue. Message [@sentinel_dapper](https://x.com/sentinel_dapper) on X first.
- **Testnet only:** never point the vault at mainnet or commit wallet files, keys or `.env` files. They're gitignored for a reason.

By contributing you agree your work is released under the [MIT License](LICENSE).
